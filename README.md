# whiskraft-legal

The public privacy policy of the mobile game **Whiskraft** by ASGS, published with GitHub Pages from the `gh-pages` branch:
https://amazingsoulgames.github.io/whiskraft-legal/

- `index.html`: the policy in English (`#en`) and Spanish (`#es`), with the "Delete your data" part (`#delete`, `#borrar-datos`).
- The game opens this URL from Settings (`LegalLinks.cs` in the game repo); Play Console uses the same URL.
- When the policy changes, change the effective date at the top of both language parts.
